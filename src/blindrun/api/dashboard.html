Blind-Run

Can a web task be completed by ear?

Blind-Run drives a virtual screen reader through a web flow and listens to every phrase it announces. If a blind user couldn't finish the task, an AI auditor names the exact barrier, a fixer writes the code change, and the fix only counts when the task can then be finished by ear.
